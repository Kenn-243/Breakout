# Breakout

A simple recreation of the classic arcade game **Breakout**, built as a learning project to practice the fundamentals of game development: collision detection, handling input, and managing game state.

## How to Play

Move the paddle left and right to bounce the ball into the bricks. Each brick you hit disappears and adds to your score. Clear every brick, but don't let the ball reach the paddle!

| Key | Action |
| --- | --- |
| ← / → (or A / D) | Move paddle |

## Features

- Paddle movement with keyboard controls
- Ball physics with wall, paddle, and brick collisions
- Lives system
- Game over screens

## What I Learned

- How a game loop works (update → draw → repeat)
- Detecting collisions between rectangles and a ball
- Changing the ball's angle based on where it hits the paddle
- Keeping track of game state (playing and game over)
